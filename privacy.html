Privacy policy

Last updated 24 November 2026.

gmail-mcp is a private tool run by DAPDEV Software Solutions OÜ, Tallinn, Estonia, for its owner's own Google accounts.

What it accesses

With the account holder's consent, gmail-mcp requests read-only access to Gmail (the gmail.readonly scope). It reads messages only when its owner asks it to, for example to search for job-alert emails. It cannot send, change or delete email.

Where the data goes

Messages are read on the owner's own computer. The access token is stored on that computer only. Email content may be passed to the AI assistant the owner runs on that computer to summarise it for him. Nothing is sold, shared with advertisers, or used to train models, and no copy is kept on any server run by DAPDEV.

Google API Services

gmail-mcp's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be withdrawn at any time at myaccount.google.com/permissions, which makes the stored token useless.
